# Cybersecurity Incident & Resilience Explorer

## Purpose

Create an evidence-led, searchable static website using the private Excel
register as its editorial source of truth.

## Current dataset

- 57 cases and milestones
- Coverage: 1971–2026
- 61 source records
- 57 controls and lessons
- 112 structured control records
- 84 incident fields

## Core design principles

- Separate technical recovery from business recovery.
- Preserve evidence status and uncertainty.
- Link claims to supporting sources.
- Distinguish malicious incidents from outages, experiments and resilience designs.
- Exclude records marked Public-safe? = No.
- Never present the dataset as comprehensive global threat intelligence.

## Initial functionality

- free-text search
- category filter
- sector filter
- technology-era filter
- date range
- evidence-status filter
- incident cards
- incident detail view
- source links
- clear-filters control
- responsive layout
- keyboard accessibility
- WCAG 2.2 AA target
